# Roadmap — Deferred Ideas

Explicitly out of scope for the MVP (CLAUDE.md §19, PLAN.md §5, tasks/todo.md). Recorded here
rather than partially implemented:

- On-chain enforcement of the pre-debit notice period (MVP treats this as an off-chain
  merchant notification only; PLAN.md §4 example B).
- Usage-based / metered billing beyond the fixed and variable capped mandate types.
- Passkey / smart-wallet onboarding as a first-class flow.
- Path payments or automatic cross-asset conversion.
- Live SEP-24 / SEP-31 / SEP-38 anchor integrations.
- x402 or MPP-style per-request micro-billing.
- Multiple merchants under one mandate.
- A protocol token.
- Governance.
- Mainnet deployment (testnet only until audit readiness).

Status: stub, revisited at the start of any phase that would otherwise expand MVP scope.
