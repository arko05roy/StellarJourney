# Paymap Level 5 User Feedback Form

Create a Google Form titled **Paymap Testnet User Feedback**. Do not pre-fill or fabricate responses.

## Form description

> Help us improve Paymap, a non-custodial recurring-payments application on Stellar testnet. Complete one genuine product flow before submitting. Your email is used only for follow-up and will not be published.

## Questions

1. **Name** — short answer, required.
2. **Email** — email validation, required.
3. **Stellar wallet address** — short answer, required.
4. **Testnet transaction hash** — short answer, required.
5. **How would you rate Paymap?** — linear scale 1–5, required. Labels: `1 = Very difficult`, `5 = Excellent`.
6. **What worked well?** — paragraph, required.
7. **What was confusing or difficult?** — paragraph, required.
8. **What should we add or improve next?** — paragraph, required.
9. **Primary use case** — multiple choice, required: Subscription; Installment; Membership; Donation; Other.
10. **May we contact you about this feedback?** — Yes/No, required.

## Settings

- Collect email addresses.
- Limit to one response only if all testers can sign in to Google; otherwise detect duplicates by wallet.
- Do not enable public response summaries.
- Show this confirmation message: `Thanks. Your response will be reviewed with your testnet transaction before it counts toward the Level 5 cohort.`

## Export

In Google Forms: **Responses → Link to Sheets**. In Google Sheets: **File → Download → Microsoft Excel (.xlsx)**. Copy genuine rows into `Paymap-User-Feedback-Analysis.xlsx`.

Before publishing proof, remove email and name columns or share aggregate screenshots only.
